## Orphest

This is the site of the (draft) YSWS Orfest for [Hack Club](https://hackclub.com/).

Dev instructions coming soon

### What does it uses ?

This is a Deno project with a Sveltekit and a [Steno](https://steno.gxbs.dev/) app. Steno is served at /docs, and Sveltekit at every other URL.

The main.ts file takes the url and serves the correct page depending on it.
