## Orphest

This is the site of the (draft) YSWS Orfest for
[Hack Club](https://hackclub.com/).

### Developping and Running

See [CONTRIBUTING.md](CONTRIBUTING.md)

### What does it uses ?

This is a Deno project with Sveltekit and [Steno](https://steno.gxbs.dev/).
Steno is served at /docs, and Sveltekit at every other URL.

The main.ts file takes the url and serves the correct page depending on it.
